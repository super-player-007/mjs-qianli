# 名将杀 · 千里单骑 自动化脚本

让《名将杀》的「千里单骑」自动跑：自动选难度、选将、走地图、战斗托管、商店/事件、结算、任务巡检，一局接一局，挂着就行。

> ⚠️ 仅用于个人账号的日常重复操作减负，请勿商用或多开刷号。

---

## 一、开始前先确认三件事

1. 模拟器开着（默认雷电模拟器），游戏已经登录进主界面；
2. 模拟器分辨率必须是 **1920×1080**、DPI 必须是 **280**——这是最容易踩的坑，改了就点偏；
3. 把游戏停在「千里单骑」入口页（选武将那一页）。

新电脑第一次用，先按 `部署文档.md` 装一次运行环境（Python 3.11 → `.venv` → 依赖 → 自检）。

## 二、三步开跑

1. 双击 `启动控制台.bat`（首次会自动生成无黑窗启动器 `启动控制台.exe`，之后可直接双击它）；
2. 确认游戏停在千里单骑入口页；
3. 点界面上的「▶ 启动」。

默认参数已经调到能直接跑，不改也能用。收工点「■ 停止」。

## 三、界面上就三块东西

- **日志 / 状态**：看它现在在干什么。卡住时看最后一行。
- **参数设置**：选武将、跑几局、先打哪些节点、商店买什么等。
- **启动 / 停止**：开跑、收工。

**参数改完要「先停止，再启动」才生效**，运行中改是不认的。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 点了启动没反应 / 提示找不到设备 | 确认模拟器和游戏都开着；点「停止」再点「启动」；仍不行就重启模拟器 |
| 点得不准、乱点 | 分辨率或 DPI 不对，改回 1920×1080 / DPI 280 |
| 卡在某个界面不动 | 看日志最后几行；现场截图在 `runtime\shots\`，把最新的日志和截图一起发给作者 |
| 改配置没效果 | 配置只在点「启动」时读取，必须停止 → 启动 |
| 杀毒软件报毒 | 常见误报，把整个文件夹加入白名单即可 |
| 挂几个小时发现断了 | Windows 电源计划改成「从不睡眠」；一睡眠模拟器时钟会错乱，程序就失联 |

## 五、几句提醒

- 挂着的时候别手动去点游戏窗口，会和程序抢点击，容易乱；
- 程序会正常消耗游戏内的军令状、门票等资源，这是跑一局本来就需要的；
- 游戏大版本更新后按钮可能变样导致识别失效，那种情况需要重新适配；
- 换电脑：把整个项目文件夹拷过去，按 `部署文档.md` 装一次运行环境，模拟器分辨率同样要 1920×1080 / DPI 280。
